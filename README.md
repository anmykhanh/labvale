# LabVale — Independent Technology R&D

**Research. Innovate. Create Value.**

Dự án nghiên cứu và phát triển công nghệ độc lập tại Việt Nam, tập trung vào:
- **Robotics:** Robot và hệ thống tự hành.
- **Drone & UAV:** Thiết bị bay không người lái.
- **Artificial Intelligence:** Trí tuệ nhân tạo & Edge AI.
- **Embedded Systems & IoT:** Hệ thống nhúng và thiết bị thông minh.
- **Software & Web:** Hạ tầng công nghệ & phần mềm.
- **Research & Development:** Thử nghiệm & đo kiểm khoa học thực tế.

## Công nghệ sử dụng
- PHP 8.2+
- MySQL / MariaDB (PDO Prepared Statements)
- Vanilla HTML5 / CSS3 / ES6+ JavaScript
- TinyMCE Rich-text Editor
- Apache `.htaccess` clean URL rewrite
